## [1.0.0] - 2026-08-25

### ✨ Added
- Initial public release of MarketingDB (`marketingdb.lol`).
- Real-time community leaderboard with interactive "Push Up" upvote mechanic.
- 24-hour IP-based vote verification to ensure fair community curation.
- Dual Turso LibSQL edge database architecture for high-speed global reads & writes.
- Instant domain metadata auto-extraction (pulls brand logo, title, and marketing pitch).
- Multi-channel filtering: UGC, Meta Ads, TikTok, Tweets/X, YouTube, Email, Copywriting, and Landing Pages.
- Free community campaign submission portal with live card preview.
- Featured Sponsor spotlight slot with direct dofollow backlink support.
- Buy Me a Coffee direct server-funding checkout integration.
- Light & Dark mode support with persistent preference storage.
- Comprehensive documentation suite (`README.md`, `CONTRIBUTING.md`, `ROADMAP.md`, `ARCHITECTURE.md`, `CHANGELOG.md`, `LICENSE.md`).

### 🎨 Design & Polish
- Custom glassmorphism UI token system.
- Web Audio API micro-sound feedback on interaction.
- Responsive mobile & desktop multi-column layouts.
